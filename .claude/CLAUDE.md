# Semiconductor Supply Chain Research Agent

## Project Purpose
Build an autonomous AI agent that tracks the semiconductor supply chain for investment research at Stanley-Laman Group.

## What This Agent Should Do
1. Monitor semiconductor industry news (TSMC, ASML, NVIDIA, AMD, Intel)
2. Track financial metrics from earnings reports
3. Map supply chain dependencies
4. Identify bottlenecks and risks
5. Generate investment insights

## Technical Approach
- Use Python for all code
- Claude Code for agentic workflow
- Web scraping with BeautifulSoup
- Data storage in JSON/CSV
- Simple visualization with Plotly or Streamlit
